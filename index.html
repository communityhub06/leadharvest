How it works

Three commands, start to list

Install

One pip command. Python 3.10 or newer, nothing else to configure.

pip install leadharvest

Point it at your URLs

Paste a list, or let it crawl a domain and find the pages itself.

leadharvest -i urls.txt --region FR

Import and send

Open the CSV in Excel or push it straight into your sequencer.

leadharvest --domain acme.fr -o leads.csv
Why it's different

Most scrapers give you noise. This gives you a list.

A regex that looks for digit patterns will happily hand you repository star counts, publish dates and Fibonacci sequences as "phone numbers". Then you spend an hour deleting them.

  • Context-aware matching. Numbers embedded in longer digit runs are rejected automatically.
  • National formats supported. Pass --region FR and 06 12 34 56 78 becomes +33612345678.
  • Consistent output. Everything is E.164 — importable into any dialler or sequencer.
  • Junk emails filtered. hero@2x.png, style@1.css and script contents never make it through.

FAQ

Straight answers

Does any of my data get sent to a third party?

No. LeadHarvest runs entirely on your machine and talks only to the websites you list. There is no telemetry, no account, no API key and no server of ours in the loop.

Why do I need --region?

Without a country hint, a bare number like 06 12 34 56 78 is ambiguous — it could belong to several countries. With no region, LeadHarvest only matches numbers already written in international form (+33…). Pass --region FR (or FR,US for mixed lists) to unlock national formats.

Will it work behind a corporate proxy or self-signed cert?

Yes — use --insecure to skip TLS verification. It is off by default because most environments should verify certificates.

What format are the phone numbers in?

E.164 — for example +33472000000. This is the format diallers, CRMs and sequencers expect, so imports don't silently fail.

Is scraping contact details legal?

You are responsible for how you use the list. Harvest only publicly published details, respect robots.txt and opt-outs, and comply with CAN-SPAM, GDPR and CASL when you message anyone.

What do I need to run it?

Python 3.10 or newer. Windows, macOS and Linux all work. No database, no Docker, no cloud account.
